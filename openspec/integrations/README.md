## Integrations

Date: 20260330

This folder contains integrator-facing materials for operating and migrating external systems that integrate with SuiteCRM.

Contents:

- `inventory/`: Integration inventory records, templates, and status definitions.
- `detection/`: Procedures and tooling for finding legacy API usage (SOAP, REST v4/v4_1).
- `v8-auth/`: OAuth2 patterns and prerequisites for V8 API integrations.
- `mapping/`: Guidance for mapping legacy SOAP/REST v4 patterns to V8 endpoints.
- `migration/`: Per-integration migration checklist, verification guidance, and templates.
- `deprecation/`: Operational runbooks for legacy endpoint retirement.
