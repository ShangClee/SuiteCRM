## Migration Playbook

Date: 20260330

This folder contains per-integration migration and verification guidance.

Use these documents with each integration inventory record:

- `checklist.md`: plan → migrate → verify → cutover → rollback.
- `acceptance-criteria-template.md`: capture workflow-level acceptance criteria.
- `parallel-run.md`: compare legacy vs V8 outcomes when dual-run is feasible.
- `rollback.md`: standard rollback guidance while legacy endpoints remain enabled.
- `parity-gaps.md`: record and resolve differences between legacy and V8 behavior.
- `gates.md`: gates for verified integrations and legacy endpoint retirement.
